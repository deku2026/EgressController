# Preview artwork

Small product-icon fixtures captured from installed Windows application resources for UI preview and
recognition checks (Claude, ChatGPT, Codex, Chrome, League of Legends, Steam, WeGame). Trademarks belong to their respective owners.
These assets are embedded only in the mock preview tool, never the production application.
Production uses the discovered Windows package/EXE icon through the native icon reader.
No private files, configuration or user process data are included.
