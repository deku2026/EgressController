# Preview artwork

Public product marks are bundled for recognition in the isolated mock workspace. No icon request occurs at runtime.

- `claude.png`, `cursor.png`, `codex.png`: [LobeHub Icons](https://github.com/lobehub/lobe-icons), static PNG light variants (`claude-color`, `cursor`, `openai`), MIT license; see LICENSE-Lobe-Icons.txt.
- Other product PNGs: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons), `png` directory, Apache-2.0; see LICENSE-Dashboard-Icons.txt.
- AppIcon.png is project-owned vector artwork rendered by MacPreview.

Product names and marks remain their owners’ property. Installed macOS application discovery uses each application bundle’s native icon through MacIconCache. These fixtures contain no private files or user configuration.
